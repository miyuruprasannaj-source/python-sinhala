පාඩම 12 : Break සහ Continue

Break සහ Continue යනු කුමක්ද?

අපි Loop එකක් (For හෝ While) ක්‍රියාත්මක වෙමින් පවතින විට, එහි ගමන් මග අපට අවශ්‍ය පරිදි පාලනය කිරීමට මෙම විධානයන් දෙක භාවිතා කරමු.

1. Break (සම්පූර්ණයෙන්ම නැවැත්වීම 🛑)

හරියට කෝච්චියක හදිසි තිරිංග (Emergency Brake) ඇද්දා වගේ, break විධානය දුන් විගසම Loop එක සම්පූර්ණයෙන්ම ක්‍රියා විරහිත වී එයින් එළියට පැමිණේ.

for i in range(1, 5):
    if i == 3:
        break
    print(i)
# ප්‍රතිඵලය: 1, 2 පමණක් print වේ. (3 දී නැවතී ඇත)

2. Continue (මඟහැර යාම ⏭️)

මෙමඟින් Loop එක සම්පූර්ණයෙන්ම නවත්වන්නේ නැත. ඒ වෙනුවට අදාළ වාරය (step) පමණක් මඟහැර (Skip කර) ඊළඟ වාරයට ගමන් කරයි.

for j in range(1, 5):
    if j == 3:
        continue
    print(j)
# ප්‍රතිඵලය: 1, 2, 4 print වේ. (3 පමණක් මඟහැරී ඇත)

ඔබේ අභ්‍යාස 💻:

දකුණු පස ඇති කේතයේ හිස්තැන් පුරවා break සහ continue වල ක්‍රියාකාරීත්වය අත්හදා බලන්න.
