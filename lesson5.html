පාඩම 05 : සංසන්දනය කිරීම (Comparison)

සංසන්දනාත්මක ක්‍රියාකරුවන් (Comparison Operators)

දත්ත දෙකක් (විශේෂයෙන් ඉලක්කම්) එකිනෙකට සංසන්දනය කිරීම සඳහා අපි මේවා භාවිතා කරමු. මෙහිදී පිළිතුර ලෙස සෑමවිටම ලැබෙන්නේ සත්‍ය (True) හෝ අසත්‍ය (False) යන Boolean අගයකි.

  • == (සමානයි): දත්ත දෙකම සමාන නම් True වේ.
    print(5 == 5) ➔ True
  • != (අසමානයි): දත්ත දෙක අසමාන නම් True වේ.
    print(10 != 5) ➔ True
  • > (විශාලයි): පළමු අගය විශාල නම් True වේ.
    print(8 > 3) ➔ True
  • < (කුඩායි): පළමු අගය කුඩා නම් True වේ.
    print(2 < 8) ➔ True
  • >= (විශාලයි හෝ සමානයි): පළමු අගය විශාල හෝ සමාන නම් True වේ.
  • <= (කුඩායි හෝ සමානයි): පළමු අගය කුඩා හෝ සමාන නම් True වේ.
වැදගත්: = සහ == යනු දෙකකි!
තනි සමාන ලකුණ (=) භාවිතා කරන්නේ Variable එකකට අගයක් ලබා දීමටයි (උදා: a = 10). නමුත් සමාන ලකුණු දෙකක් (==) භාවිතා කරන්නේ අගයන් දෙකක් එකිනෙකට සමාන දැයි පරීක්ෂා කිරීමටයි.

ඔබේ අභ්‍යාසය 💻:

දකුණු පස කේතයේ x ට 15 ත්, y ට 20 ත් ලබා දී ඇත. print() භාවිතා කර පහත දේවල් පරීක්ෂා කර බලන්න:

  1. x සහ y සමානද?
  2. x, y ට වඩා කුඩාද?
  3. x සහ y අසමානද?
