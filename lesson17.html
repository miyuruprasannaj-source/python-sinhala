සිංහලෙන් Python

📢 විශේෂ නිවේදනයයි!

🚀 Problem Solving Series එකට සූදානම්ද?

අපි මේ වෙනකන් Python වල ගොඩක් දේවල් ඉගෙන ගත්තා. Variables, If/Else කොන්දේසි, Loops, Lists වගේම Strings ගැනත් අපි දැන් දන්නවා. මීළඟට අපිට ඉගෙන ගන්න තියෙන වැදගත්ම මාතෘකාව තමයි "Functions (ශ්‍රිත)".

නමුත් ඊට කලින් පොඩි වැඩක් තියෙනවා! 🧠

සාර්ථක මෘදුකාංග ඉංජිනේරුවෙක් (Software Engineer) වෙන්න නම්, කේතය (Syntax) කටපාඩම් කරනවාට වඩා, ගැටළුවක් දිහා බලලා ඒක විසඳන තර්කය (Logic) ගොඩනඟන්න පුරුදු වෙන්න ඕනේ.

ඒ නිසා, Functions පාඩමට යන්න කලින් අපි විශේෂ "ගැටළු විසඳීමේ මාලාවක් (Problem Solving Series)" පටන් ගන්නවා. මෙතෙක් ඉගෙන ගත් සියලුම දේවල් එකතු කරලා ප්‍රායෝගික ප්‍රශ්න කිහිපයක් විසඳන්නයි අපි දැන් යන්නේ.

අභියෝගය භාරගන්නවාද? 🤝

ඔබ මේ අභියෝගය භාරගන්නවා නම්, දකුණු පස කේත සංස්කාරකයේ ඇති ready යන variable එකේ අගය True ලෙස වෙනස් කර, එය Run කරන්න.

එය නිවැරදිව කළ විට, ප්‍රශ්න මාලාවේ පළමු අභ්‍යාසයට යාමට ඇති බොත්තම විවෘත වනු ඇත!
