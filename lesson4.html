පාඩම 04 : දත්ත වර්ග (Data Types)

මූලික දත්ත වර්ග (Basic Data Types)

පරිගණකයට අපි ලබාදෙන දත්ත එකිනෙකට වෙනස්. Python භාෂාවේ ප්‍රධාන වශයෙන් භාවිතා වන දත්ත වර්ග 4ක් ඇත:

  1. Integer (int): පූර්ණ සංඛ්‍යා. දශම තිතක් නොමැති ධන හෝ සෘණ ඉලක්කම්.
    (උදා: 10, -5, 2026)
  2. Float (float): දශම සංඛ්‍යා.
    (උදා: 10.5, 3.14, -2.5)
  3. String (str): වචන හෝ අකුරු. මේවා අනිවාර්යයෙන්ම උද්ධෘත ලකුණු ("" හෝ '') ඇතුළේ ලිවිය යුතුය.
    (උදා: "Miyuru", 'Python')
  4. Boolean (bool): සත්‍ය හෝ අසත්‍ය බව පෙන්වන දත්ත. මෙහි ඇත්තේ අගයන් දෙකක් පමණි: True සහ False. (මුල් අකුර අනිවාර්යයෙන්ම Capital විය යුතුය).

type() ශ්‍රිතය:

අපිට variable එකක තියෙන්නේ මොන වර්ගයේ දත්තයක්ද කියලා හරියටම බලාගන්න type() කියන ශ්‍රිතය පාවිච්චි කරන්න පුළුවන්.

print(type(age))

ඔබේ අභ්‍යාසය 💻:

දකුණු පස ඇති කේතයේ variables හතරක් සාදා ඇත. type() ශ්‍රිතය භාවිතා කර ඒවායේ Data Type එක Terminal එකේ print කර බලන්න.
