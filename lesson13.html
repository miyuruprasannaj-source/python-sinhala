පාඩම 13 : Strings සහ Mutability

1. F-Strings (කෙටි හා ලස්සන ක්‍රමය)

අපි මීට පෙර Variables සහ වචන එකට එකතු කරලා print කරද්දී ක්‍රම කිහිපයක් පාවිච්චි කළා. නමුත් Python වල තියෙන ලේසිම සහ නවීනතම ක්‍රමය තමයි f-strings.

මෙහිදී වාක්‍යය පටන්ගන්න කලින් f අකුර දමා, Variable එකේ නම කෙලින්ම සඟල වරහන් {} ඇතුළේ ලියන්න පුළුවන්.

උදාහරණ:
name = "කමල්"
print(f"මගේ නම {name} වේ.")

2. Mutable සහ Immutable කියන්නේ මොකක්ද?

Python වල අපි හදන හැම දත්තයක්ම ප්‍රධාන වර්ග දෙකකට බෙදෙනවා:

  • Mutable (වෙනස් කළ හැකි): හැදුවට පස්සෙත් ඇතුළේ තියෙන දේවල් මකන්න, අලුතින් දාන්න පුළුවන් දේවල්. (උදා: අපි කලින් ඉගෙන ගත්ත Lists).
  • Immutable (වෙනස් කළ නොහැකි): මේවා හැදුවාට පස්සේ ආයෙමත් ඇතුළේ තියෙන දේවල් වෙනස් කරන්න බැහැ. Strings කියන්නේ Immutable දත්ත වර්ගයක්!
🚨 String එකක් වෙනස් කරන්න බැහැ!
උදාහරණයක් විදිහට word = "Cat" කියලා හදලා, පළවෙනි අකුර "B" කරලා ඒක "Bat" කරන්න (word[0] = "B") අපිට බැහැ. එහෙම කළොත් පරිගණකය Error එකක් ලබා දෙනවා.

ඔබේ අභ්‍යාස 💻:

දකුණු පස ඇති කේතයේ අභ්‍යාස 1 සම්පූර්ණ කරන්න. ඉන්පසු අභ්‍යාස 2 හි ඇති Error එක ප්‍රායෝගිකව අත්හදා බලන්න.
