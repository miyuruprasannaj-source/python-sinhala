පාඩම 15 : දෝෂ කළමනාකරණය (Exception Handling)

වැඩසටහනක් Crash වෙන්නේ ඇයි?

මෘදුකාංග ඉංජිනේරුවන් විදිහට අපි ලියන කේතය කොතරම් නිවැරදි වුවත්, පරිශීලකයා (User) වැරදි දත්තයක් ලබා දුනහොත් හෝ පරිගණකයේ දෝෂයක් ආවොත් වැඩසටහන රතු පාටින් Error එකක් පෙන්වා සම්පූර්ණයෙන්ම කඩා වැටෙනවා (Crash). මෙය Exception එකක් ලෙස හඳුන්වයි.

ඒක ගොඩදාගන්නේ කොහොමද? (try / except)

කඩා වැටෙන්න පුළුවන් අවදානම් කේතය අපි try බ්ලොක් එක ඇතුළේ ලියනවා. යම් හෙයකින් Error එකක් ආවොත් Crash වෙන්නේ නැතිව, එය except බ්ලොක් එක මගින් අල්ලාගෙන අපිට අවශ්‍ය පණිවිඩයක් ලබා දෙනවා.

try:
    # අවදානම් කේතය මෙහි ලියන්න
    ans = 10 / 0
except:
    # Error එකක් ආවොත් පමණක් මෙතැන run වේ
    print("සමාවෙන්න, දෝෂයක් හටගත්තා!")

අනිවාර්යයෙන්ම දැනගත යුතු Exceptions 10ක්

  1. ZeroDivisionError: ඉලක්කමක් 0 න් බෙදීමට යාම.
  2. ValueError: වැරදි දත්ත වර්ගයක් ලබා දීම (උදා: int විය යුතු තැනක අකුරු දීම).
  3. TypeError: නොගැලපෙන දත්ත වර්ග එකතු කිරීමට යාම (උදා: ඉලක්කම් සහ අකුරු එකතු කිරීම).
  4. NameError: අප කලින් සාදා නොමැති Variable එකක් භාවිතා කිරීමට යාම.
  5. IndexError: List එකක නොමැති ස්ථානයක් (Index) සෙවීමට යාම.
  6. KeyError: Dictionary එකක නැති Key එකක් සෙවීමට යාම.
  7. SyntaxError: කේතය ලිවීමේ ව්‍යාකරණ දෝෂ (උදා: වරහන් වසා නොතිබීම).
  8. IndentationError: හිස්තැන් (Spaces/Tabs) වැරදීම.
  9. FileNotFoundError: පරිගණකයේ නැති ගොනුවක් (File) විවෘත කිරීමට යාම.
  10. AttributeError: දත්ත වර්ගයකට අදාළ නැති method එකක් භාවිතා කිරීම.

ඔබේ අභ්‍යාසය 💻:

දකුණු පස කේතයේ මුලින්ම ඉලක්කම ලෙස 0 ලබා දී 'Run' කර එය කඩා වැටෙන (Crash) ආකාරය බලන්න. ඉන්පසු try සහ except යොදාගෙන එය කඩා නොවැටී සුමටව ක්‍රියා කරන ලෙස සකස් කරන්න.
