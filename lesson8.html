පාඩම 08 : ලැයිස්තු (Lists)

ලැයිස්තුවක් (List) යනු කුමක්ද?

සාමාන්‍යයෙන් Variable (විචල්‍ය) එකක ගබඩා කරන්න පුළුවන් එක දත්තයක් විතරයි. නමුත් අපිට දත්ත ගොඩක් එකවර ගබඩා කරගන්න ඕනේ නම් අපි List එකක් භාවිතා කරනවා. හරියට කඩේට යනකොට හදාගන්න බඩු ලැයිස්තුවක් වගේ.

List එකක් හදන්නේ කොටු වරහන් [] භාවිතා කරලයි.

උදාහරණ:
fruits = ["Apple", "Banana", "Mango"]
marks = [75, 80, 95]

ඔබේ පළමු අභ්‍යාසය 💻:

colors නමින් List එකක් සාදා, ඊට ඔබේ කැමතිම පාට 3ක් (String ලෙස) ඇතුළත් කර print(colors) මගින් එය පෙන්වන්න.

List එකක් වෙනස් කිරීම (List Operations)

හදාගත්ත List එකක් අපිට ඕනේ විදිහට පාලනය කරන්න විශේෂ ක්‍රම (Syntax) කිහිපයක් තියෙනවා:

1. Index (ස්ථානය):
පරිගණකය ගණන් කරන්න පටන් ගන්නේ 1න් නෙමෙයි, 0න්. ඒ නිසා List එකක පළවෙනි අයිතමය තියෙන්නේ 0 වෙනි ස්ථානයේයි (Index 0).
print(fruits[0]) ➔ Apple
  • අලුතින් යමක් එකතු කිරීමට (Append):
    fruits.append("Orange") අගට එකතු වෙයි.
  • යමක් ඉවත් කිරීමට (Remove):
    fruits.remove("Banana")
  • List එකේ දිග සෙවීමට (Length):
    print(len(fruits)) (මෙහි අයිතම කීයක් ඇද්දැයි ඉලක්කමෙන් පෙන්වයි).

ඔබේ දෙවන අභ්‍යාසය 💻:

දකුණු පස ඇති කේතයේ numbers නමින් List එකක් සාදා ඇත.

  1. එම List එකට 40 අලුතින් එකතු කරන්න (Append භාවිතා කර).
  2. ඉන්පසු එම List එකේ ඇති පළමු අගය (එනම් 10) පමණක් Index එක භාවිතා කර print කරන්න.
  3. අවසානයේ List එකේ මුළු දිග (Length එක) කීයදැයි print කරන්න.
