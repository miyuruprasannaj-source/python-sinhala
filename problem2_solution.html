සිංහලෙන් Python

විසඳුම 02 : "A" අකුරේ රහස

කේතයේ තර්කය (Logic) තේරුම් ගනිමු 🧠

පේන්න ලේසි වුණාට "A" අකුරක් අඳිනවා කියන්නේ කොටස් දෙකකට කඩලා හිතන්න ඕනේ වැඩක්. අපි කොන්දේසිය (If condition) හැදුවේ මෙහෙමයි:

(col == 0 or col == 4) and row != 0
1. වම් සහ දකුණු කණු: අපි 0 සහ 4 කියන තීරු වල (වමේම සහ දකුණේම) තරු අඳිනවා. හැබැයි row != 0 (0 වෙනි පේළිය නොවිය යුතුයි) කියලා දුන්නේ නැත්නම් අකුරේ උඩ කොටුවක් වගේ වෙනවා. මේකෙන් අකුරේ උඩ හැඩය ලස්සන වෙනවා.
(row == 0 or row == 3) and (col > 0 and col < 4)
2. හරස් රේඛා දෙක: 0 වෙනි පේළියේ (උඩම) සහ 3 වෙනි පේළියේ (මැද) හරහට රේඛාවක් ඕනේ. හැබැයි ඒක මැද තීරු (1, 2, 3) වලට විතරක් සීමා කරන්න තමයි col > 0 and col < 4 කියන කොටස පාවිච්චි කළේ.
print("*", end="") සහ print()
3. මුද්‍රණය කිරීම: end="" මඟින් අලුත් පේළියකට යන්නේ නැතුව එක ළඟ තරු (හෝ හිස්තැන්) මුද්‍රණය කරනවා. ඇතුළේ Loop එක (තීරු 5) දුවලා ඉවර වුණාම, පිටත Loop එකේ තියෙන හිස් print() එක මඟින් අලුත් පේළියකට යනවා.

දැන් දකුණු පස ඇති 'Run Code' ඔබලා, අපූරුවට "A" අකුර මුද්‍රණය වන හැටි බලන්න.
