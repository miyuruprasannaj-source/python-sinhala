පාඩම 07 : Nested Conditions

කොන්දේසි ඇතුළේ කොන්දේසි (Nested If)

"Nested" කියන්නේ එකක් ඇතුළේ තව එකක් තියෙනවා කියන අදහසයි. අපි සාමාන්‍ය ජීවිතයේදීත් එක කොන්දේසියක් හරි ගියාට පස්සේ තව කොන්දේසියක් පරීක්ෂා කරනවා නේද? (උදා: මුලින්ම වයස 18ට වැඩිද බලනවා. ඒක හරි නම් විතරයි ඊළඟට විභාගය පාස්ද කියලා බලලා ලයිසන් එක දෙන්නේ).

Python වලදී if එකක් ඇතුළේ තවත් if එකක් ලියන්න අපිට පුළුවන්. පළවෙනි (පිටත තියෙන) කොන්දේසිය True වුණොත් විතරයි පරිගණකය ඇතුළට ගිහින් දෙවෙනි කොන්දේසිය පරීක්ෂා කරන්නේ.

උදාහරණයක්:
if වයස >= 18:
    if ටිකට්_එක_තියෙනවාද == True:
        print("ඔබට ඇතුළට යා හැක")
    else:
        print("ඔබට ටිකට් එකක් අවශ්‍යයි")
else:
    print("ඔබේ වයස ප්‍රමාණවත් නැත")
Indentation (හිස්තැන් තැබීම): ඇතුළත ඇති if සහ else ලිවිය යුත්තේ පිටත ඇති කේතයට වඩා තවත් එක් Tab එකක් (හිස්තැන් 4ක්) ඇතුළට වන්නටය.

exercise:

ඔබ දැන් බැංකුවක "ණය අනුමත කිරීමේ පද්ධතියක්" (Loan Approval System) සෑදිය යුතුය. දකුණු පස ඇති කේතයේ පුද්ගලයෙකුගේ මාසික ආදායම (income) සහ ණය වාර්තාවේ ලකුණු (credit_score) ලබා දී ඇත.

  1. පළමුව මාසික ආදායම 50000 ට වඩා වැඩිද හෝ සමානද (>=) යන්න පරීක්ෂා කරන්න.
  2. එය සම්පූර්ණ නම්, ඊළඟට (ඇතුළත if එකෙන්) ණය වාර්තාව 700 ට වැඩිද හෝ සමානද පරීක්ෂා කරන්න. එයත් සම්පූර්ණ නම් "ණය මුදල අනුමතයි!" ලෙස print කරන්න.
  3. ආදායම හරි ගොස්, ණය වාර්තාව මදි නම් (ඇතුළත else කොටස) "ණය වාර්තාව ප්‍රමාණවත් නැත." ලෙස print කරන්න.
  4. මුලින්ම බලන ආදායම 50000ට වඩා අඩු නම් (පිටත else කොටස) කෙලින්ම "මාසික ආදායම ප්‍රමාණවත් නැත." ලෙස print කරන්න.
