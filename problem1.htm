සිංහලෙන් Python

ගැටළුව 01 : Calculator (ගණක යන්ත්‍රය)

ඔබේ පළමු මෘදුකාංගය හදමු! 💻

දැන් අපි ඉගෙනගත්ත Variables, Input, If/Else සහ Loops පාවිච්චි කරලා සරල Calculator (ගණක යන්ත්‍රයක්) හදන්නයි යන්නේ.

ඔබ කළ යුතු දේ:

  1. පරිශීලකයාගෙන් පළමු අංකය ඉල්ලා සිටින්න (input() සහ float() භාවිතා කරන්න).
  2. අවශ්‍ය ගණිත කර්මය (+, -, *, /) කුමක්දැයි ඉල්ලා සිටින්න.
  3. දෙවන අංකය ඉල්ලා සිටින්න.
  4. if / elif / else භාවිතා කර අදාළ ගණනය කිරීම සිදුකර පිළිතුර print කරන්න.
  5. (අභියෝගය): මේ සම්පූර්ණ කේතයම while True: ලූප් එකක් ඇතුළේ ලියන්න. පරිශීලකයා 'exit' යැයි type කළ විට break භාවිතා කර එය නවත්වන්න.

බිය නොවන්න! ඔබට හැකි පමණින් දකුණු පස කේතය ලියා අත්හදා බලන්න. උත්සාහ කිරීමයි වැදගත්. කොතැන හෝ හිර වුණොත්, අපි ඊළඟ පිටුවෙන් මෙහි සම්පූර්ණ විසඳුම පියවරෙන් පියවර පැහැදිලි කරමු.
