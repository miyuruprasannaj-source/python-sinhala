පාඩම 14 : Strings වල විශේෂ උපක්‍රම

Strings එකතු කිරීම සහ ගුණ කිරීම (+ සහ *)

Python වල ඉලක්කම් වගේම වචනත් (Strings) එකට එකතු කරන්න වගේම ගුණ කරන්නත් පුළුවන්! මෙය ඉතා ප්‍රයෝජනවත් උපක්‍රමයකි.

  • එකතු කිරීම (Concatenation): + ලකුණ භාවිතා කර වචන දෙකක් ඈඳිය හැක.
    print("Hello" + "World") ➔ HelloWorld
  • ගුණ කිරීම (Repetition): * ලකුණ භාවිතා කර වචනයක් කිහිප වතාවක් අනුක්‍රමණය කළ හැක.
    print("Ha" * 3) ➔ HaHaHa

ඉතා වැදගත් String Methods

Strings වෙනස් කරන්න බැරි (Immutable) වුණාට, ඒකේ තියෙන අකුරු වල හැඩය මාරු කරලා අලුත් වචනයක් විදිහට ගන්න අපිට Methods පාවිච්චි කරන්න පුළුවන්.

  • .upper() : සියලුම අකුරු Capital (විශාල) කරයි.
    print("python".upper()) ➔ PYTHON
  • .lower() : සියලුම අකුරු Simple (කුඩා) කරයි.
    print("PYTHON".lower()) ➔ python
  • .replace() : වචනයක් ඇතුළේ තියෙන අකුරක් වෙනුවට වෙනත් අකුරක් ආදේශ කරයි.
    print("Cat".replace("C", "B")) ➔ Bat
  • .split() : වාක්‍යයක් කෑලි වලට කඩා List එකක් බවට පත් කරයි.
    print("A,B,C".split(",")) ➔ ['A', 'B', 'C']
