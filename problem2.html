සිංහලෙන් Python

ගැටළුව 02 : තරු (*) අකුරු

අලුත් උපක්‍රම 2ක් ඉගෙන ගනිමු 💡

1. print() හි සැඟවුණු රහස (end="")

සාමාන්‍යයෙන් print("*") කියල දුන්නම, තාරකාව print වෙලා ඊළඟ දේ පටන් ගන්නේ අලුත් පේළියකිනුයි. හැබැයි අපිට තරු එක පෙළට (තිරස් අතට) ලියන්න ඕනේ නම්, අපි print("*", end="") ලෙස ලබා දිය යුතුය. මෙයින් අලුත් පේළියකට යෑම නවතී.

2. Nested Loops (ලූප් ඇතුළේ ලූප්)

පේළි (Rows) සහ තීරු (Columns) පාලනය කරන්න අපි Loop එකක් ඇතුළේ තවත් Loop එකක් ලියනවා. පිටතින් ඇති ලූප් එකෙන් "පේළිය" ද, ඇතුළත ඇති ලූප් එකෙන් එම පේළියේ ඇති "තීරු" ද පාලනය වේ.

අභියෝගය: "A" අකුර අඳිමු! 🎨

දකුණු පස ඇති කේතයේ අපි පේළි 7ක් සහ තීරු 5ක් (7x5) සඳහා Nested Loop එකක් හදා ඇත. ඔබ කළ යුත්තේ if Condition එක සම්පූර්ණ කිරීමයි.

"A" අකුර සඳහා තරු වැටිය යුතු ස්ථාන:
  1. වම් සහ දකුණු කණු: තීරුව (col) 0 හෝ 4 වූ විට. (නමුත් උඩම පේළිය (row 0) නොවිය යුතුය, නැතහොත් උඩින් කොටු වේ)
  2. හරස් රේඛා 2: පේළිය (row) 0 හෝ 3 වූ විට. (මෙය මැද තීරු වලට පමණක් සීමා විය යුතුය, එනම් col > 0 සහ col < 4)

පහත කේතයේ Comment කර ඇති කොටස් කියවා කේතය සම්පූර්ණ කර 'Run' කරන්න. හිර වුණොත් බයවෙන්න එපා, ඊළඟ පිටුවෙන් අපි විසඳුම පැහැදිලි කරමු!
