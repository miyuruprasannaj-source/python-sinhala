පාඩම 11 : While Loop

While Loop එකක් යනු කුමක්ද?

While loop එකක ප්‍රධානම අදහස තමයි, "මෙකෙ දීලා තියෙන condition (කොන්දේසිය) True වෙලා තියෙනකම් මේක දිගටම Run වෙනවා" යන්නයි.

උදාහරණයක් බලමු: 
i = 1
while i <= 3:
    print("ආයුබෝවන්!")
    i = i + 1
🚨 අමතක කරන්න එපා (Infinite Loop): ඉහත උදාහරණයේ i = i + 1 (හෝ i += 1) කියා අපි අගය වෙනස් කළේ නැත්නම්, i හි අගය හැමදාම 1 මයි. එතකොට කොන්දේසිය හැමදාම True වෙන නිසා Loop එක කවදාවත් නවතින්නේ නැහැ! මෙය Infinite Loop එකක් ලෙස හඳුන්වයි.

True While Loop (සදහටම දුවන ලූප්)

සමහර අවස්ථාවල අපිට ඕනෑකමින්ම කොන්දේසියක් නැතුව දිගටම වැඩසටහන Run කරගන්න අවශ්‍ය වෙනවා (උදා: ගේම් එකක්). ඒ සඳහා අපි while True: භාවිතා කරමු. නමුත් එයින් පිටවීමට break යන වචනය අනිවාර්යයෙන් ලිවිය යුතුය.

while True:
    print("දිගටම වැඩ")
    break # මෙතැනදී බලහත්කාරයෙන් නවතී

ඔබේ අභ්‍යාස 💻:

දකුණු පස ඇති කේත සංස්කාරකයේ අභ්‍යාස 5 පිළිවෙළින් ලියා 'Run Code' ඔබන්න.
