පාඩම 06 : කොන්දේසි (Part 1)

කොන්දේසි (If / Elif / Else)

පරිගණකයට තීරණයක් ගැනීමට අවශ්‍ය වූ විට අපි කොන්දේසි (Conditions) භාවිතා කරමු. මෙහි ප්‍රධාන කොටස් 3ක් ඇත:

  • if (නම්): if එක ඇතුළේ දීලා තියෙන condition එක True නම්, ඒක ඇතුළේ තියෙන කේතය (code එක) run වෙනවා.
  • elif (නැත්නම් මේක නම්): if එක True නැත්නම්, ඊළඟට elif වල දීලා තියෙන conditions අනුපිළිවෙලට check වෙනවා.
  • else (නැත්නම්): ඔය උඩ තියෙන කිසිම condition එකක් True වුණේ නැත්නම් තමයි අවසානයේ else එක run වෙන්නේ.
විශේෂයි: if එකක් පාවිච්චි කරන හැම අවස්ථාවකම elif හෝ else අනිවාර්යයෙන්ම තිබිය යුතු නැහැ. අවශ්‍ය නම් ඔබට if පමණක් තනිවම වුවද භාවිතා කළ හැක.

සැලකිය යුතුයි: Python වල if/elif/else ලිවීමේදී කොන්දේසිය අවසානයේ කෝලන් ලකුණ (:) අනිවාර්ය වන අතර, ඊට යටින් ලියන කේතය Tab එකක් (හිස්තැන්) ඇතුලට වන්නට ලිවිය යුතුය (Indentation).

ඔබේ අභ්‍යාසය 💻:

විභාග ලකුණු අනුව ශ්‍රේණිය (Grade) ලබා දෙන පද්ධතියක් සාදමු. දකුණු පස ඇති කේතයේ marks = 82 ලෙස දී ඇත.

  1. ලකුණු 75 හෝ ඊට වැඩි (>= 75) නම් "A" ලෙසද,
  2. ලකුණු 65 හෝ ඊට වැඩි (>= 65) නම් "B" ලෙසද,
  3. ලකුණු 50 හෝ ඊට වැඩි (>= 50) නම් "C" ලෙසද,
  4. ඉහත කිසිවක් නොවේ නම් "F" ලෙසද Print වීමට elif සහ else යොදා කේතය සම්පූර්ණ කරන්න.
