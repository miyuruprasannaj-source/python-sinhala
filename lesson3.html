පාඩම 03 : විචල්‍ය (Variables) සහ Type Casting

දත්ත ගබඩා කිරීම - Variables

Variable එකක් කියන්නේ හරියට භාජනයක් (Container) වගේ දෙයක්. අපිට අවශ්‍ය දත්තයක් කෙටි කාලයකට පරිගණකයේ ගබඩා කරලා තියාගන්න මේ භාජන පාවිච්චි කරනවා.

පරිශීලකයාගෙන් දත්ත ලබා ගැනීම - input()

අපිම කේතය ඇතුළේ දත්ත ලබා දෙනවාට වඩා, වැඩසටහන භාවිතා කරන කෙනාගෙන් (User) දත්තයක් ඉල්ලා සිටීමට input() ශ්‍රිතය භාවිතා කළ හැක.

🚨 ඉතා වැදගත් (Type Casting):
input() ශ්‍රිතයෙන් ලබාගන්නා ඕනෑම දෙයක් Python භාරගන්නේ String එකක් (වචනයක් හෝ අකුරු) ලෙසයි. ඔබ වයස ලෙස 18 ලබා දුන්නත්, පරිගණකය එය දකින්නේ "18" ලෙසයි. එබැවින් වචන යොදාගෙන ගණනය කිරීම් (එකතු කිරීම්, අඩු කිරීම්) කළ නොහැක!

ගණනය කිරීම් කිරීමට පෙර එම වචනය අංකයක් (Number) බවට පත් කළ යුතුය. මේ සඳහා අපි දත්ත වර්ගය වෙනස් කිරීම හෙවත් Type Casting භාවිතා කරමු.

  • int() : පූර්ණ සංඛ්‍යා (නිඛිල) බවට පත් කිරීමට. (උදා: 10, -5, 2026)
  • float() : දශම සංඛ්‍යා බවට පත් කිරීමට. (උදා: 10.5, 3.14)
උදාහරණ:
age_str = input("වයස කීයද? ")
age = int(age_str) (මෙහිදී වචනය අංකයක් බවට පත් වේ)

කෙටි ක්‍රමය (එක පේළියෙන්):
age = int(input("වයස කීයද? "))

ඔබේ අභ්‍යාසය 💻:

අපි දැන් පරිශීලකයාගේ උපන් වර්ෂය අසා, ඔහුගේ වයස ගණනය කරමු.

  1. birth_year නමින් variable එකක් සාදා input() මගින් උපන් වර්ෂය ඉල්ලන්න.
  2. එම අගය int() භාවිතා කර අංකයක් බවට පත් කරන්න.
  3. age = 2026 - birth_year ලෙස වයස ගණනය කරන්න.
  4. අවසානයේ print("ඔබේ වයස:", age) ලෙස පෙන්වන්න. ('Run Code' එබූ විට ඉහළින් එන කොටුවේ වර්ෂය Type කර 'OK' දෙන්න).
