සිංහලෙන් Python

පාඩම 03 : විචල්‍ය (Variables)

දත්ත ගබඩා කිරීම - Variables

Variable එකක් කියන්නේ හරියට භාජනයක් (Container) වගේ දෙයක්. අපිට අවශ්‍ය දත්තයක් (වචනයක් හෝ ඉලක්කමක්) කෙටි කාලයකට පරිගණකයේ ගබඩා කරලා තියාගන්න මේ භාජන පාවිච්චි කරනවා. තවත් විදිහකින් කිව්වොත්, මේක අපි දත්තයකට ලබා දෙන නමක්.

උදාහරණ:
item = "පොත" (වචන ගබඩා කරන විට උද්ධෘත ලකුණු "" අවශ්‍යයි)

price = 250 (ඉලක්කම් ගබඩා කරන විට උද්ධෘත ලකුණු අවශ්‍ය නැත)

මූලික නීති (Rules for Variables):

  1. නම ආරම්භ විය යුත්තේ ඉංග්‍රීසි අකුරකින් හෝ underscore (_) පමණි. ඉලක්කමකින් පටන් ගත නොහැක.
    (උදා: 1st_number ❌ වැරදියි, number_1 ✅ නිවැරදියි).
  2. නම මැද හිස්තැන් (Spaces) තැබිය නොහැක. වචන වෙන් කිරීමට underscore (_) භාවිතා කරන්න.
    (උදා: my age ❌ වැරදියි, my_age ✅ නිවැරදියි).
  3. Python භාෂාවට ආවේණික විශේෂ වචන (print, if වැනි) නම් ලෙස භාවිතා කළ නොහැක.

ඔබේ අභ්‍යාසය 💻:

Variables භාවිතයෙන් ඉලක්කම් සුළු කිරීමක් (ගණනය කිරීමක්) කරමු.

  1. a නමින් variable එකක් සාදා ඊට 45 ලබා දෙන්න.
  2. b නමින් තවත් variable එකක් සාදා ඊට 15 ලබා දෙන්න.
  3. දැන් total නමින් අලුත් variable එකක් සාදා, ඊට ඉහත a සහ b හි එකතුව (a + b) සමාන කරන්න.
  4. අවසානයේ print(total) භාවිතා කර අගය තිරයේ දිස්වීමට සලස්වන්න.
